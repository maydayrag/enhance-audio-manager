Enhance Audio Manager 音訊管理器

作者：圓臉。

介紹

版本：1.1。透過鍵盤管理 Windows 播放與錄音裝置、應用程式音量、麥克風增量及 NVDA 輸出裝置，並提供語音與點字回饋。

支援 NVDA 2026.2，最低需求為 NVDA 2026.1.1。

提供英文與繁體中文介面翻譯及說明文件，依 NVDA 的語言設定使用。

安裝與操作

在 NVDA 執行時開啟 enhanceAudioManager-1.1.nvda-addon，依提示安裝並重新啟動 NVDA。使用下方快速鍵選取播放裝置、錄音裝置或音訊應用程式，再調整所選目標的音量、靜音或裝置。筆電快速鍵適用於 NVDA 的筆電鍵盤配置。

所有指令都能在 NVDA 的「輸入手勢」對話框中搜尋「Enhance Audio Manager 音訊管理器」並重新指定。

每次調整音量會增減 1%，設定成功後會立即將目前音量數字送至 NVDA 語音與點字顯示。瀏覽到清單第一項或最後一項後不會循環；繼續往外移動時會播放短嗶聲。

插入或移除音訊裝置後，附加元件會在下一次瀏覽或切換靜音時重新取得 Windows 的有效裝置清單；連續調整音量時沿用目前介面，僅在介面失效時重新同步並重試。

清單為空是正常狀態，不會寫入 NVDA 記錄。附加元件會依操作內容報讀「沒有任何輸出裝置」、「沒有任何輸入裝置」、「沒有任何音訊應用程式」或「沒有任何 NVDA 輸出裝置」。

靜音、取消靜音或設為預設裝置等操作，會先報讀狀態，再報讀裝置或應用程式名稱。

NVDA 啟動後，附加元件會檢查所有有效播放裝置，解除靜音，並將音量為 0 的播放裝置設為 50%；非零的播放音量維持不變。

預設快速鍵

桌機配置

  • 上一個播放裝置：Control+Windows+Alt+數字鍵盤 4。
  • 下一個播放裝置：Control+Windows+Alt+數字鍵盤 6。
  • 上一個錄音裝置：Control+Windows+Alt+數字鍵盤 1。
  • 下一個錄音裝置：Control+Windows+Alt+數字鍵盤 3。
  • 上一個音訊應用程式：Control+Windows+Alt+數字鍵盤 7。
  • 下一個音訊應用程式：Control+Windows+Alt+數字鍵盤 9。
  • 提高所選目標音量：Control+Windows+Alt+數字鍵盤 8。
  • 降低所選目標音量：Control+Windows+Alt+數字鍵盤 2。
  • 提高麥克風增量：Control+Windows+數字鍵盤 8。
  • 降低麥克風增量：Control+Windows+數字鍵盤 2。
  • 切換所選目標靜音：Control+Windows+Alt+數字鍵盤 5。
  • 將所選裝置設為 Windows 預設裝置：Control+Windows+Alt+數字鍵盤 Enter。
  • 下一個 NVDA 輸出裝置：Control+Windows+Alt+數字鍵盤加號。
  • 上一個 NVDA 輸出裝置：Shift+Control+Windows+Alt+數字鍵盤加號。
  • 鎖定或解除鎖定預設麥克風音量：Control+Windows+Alt+數字鍵盤 Delete。
  • 下一個應用程式播放裝置：Control+Windows+Alt+數字鍵盤乘號。
  • 上一個應用程式播放裝置：Shift+Control+Windows+Alt+數字鍵盤乘號。
  • 下一個應用程式錄音裝置：Control+Windows+Alt+數字鍵盤除號。
  • 上一個應用程式錄音裝置：Shift+Control+Windows+Alt+數字鍵盤除號。
  • 重設所有應用程式裝置：Control+Windows+Alt+數字鍵盤減號。連按兩次會將播放裝置音量設為 50，應用程式與錄音裝置音量設為 100，並全部取消靜音。
  • 快速切換預設麥克風靜音：Shift+Control+Windows+Alt+數字鍵盤 2。
  • 快速切換預設系統聲音靜音：Shift+Control+Windows+Alt+數字鍵盤 5。
  • 切換目前視窗應用程式靜音：Shift+Control+Windows+Alt+數字鍵盤 8。

筆電配置

  • 上一個播放裝置：Control+Windows+Alt+Page Up。
  • 下一個播放裝置：Control+Windows+Alt+Page Down。
  • 上一個錄音裝置：Control+Windows+Alt+Home。
  • 下一個錄音裝置：Control+Windows+Alt+End。
  • 上一個音訊應用程式：Control+Windows+Alt+向左鍵。
  • 下一個音訊應用程式：Control+Windows+Alt+向右鍵。
  • 提高所選目標音量：Control+Windows+Alt+向上鍵。
  • 降低所選目標音量：Control+Windows+Alt+向下鍵。
  • 提高麥克風增量：Control+Windows+向上鍵。
  • 降低麥克風增量：Control+Windows+向下鍵。
  • 切換所選目標靜音：Control+Windows+Alt+空白鍵。
  • 將所選裝置設為 Windows 預設裝置：Control+Windows+Alt+Enter。
  • 下一個 NVDA 輸出裝置：Control+Windows+Alt+反斜線。
  • 上一個 NVDA 輸出裝置：Shift+Control+Windows+Alt+反斜線。
  • 鎖定或解除鎖定預設麥克風音量：Control+Windows+Alt+Delete。
  • 下一個應用程式播放裝置：Control+Windows+Alt+右中括號。
  • 上一個應用程式播放裝置：Shift+Control+Windows+Alt+右中括號。
  • 下一個應用程式錄音裝置：Control+Windows+Alt+左中括號。
  • 上一個應用程式錄音裝置：Shift+Control+Windows+Alt+左中括號。
  • 重設所有應用程式裝置：Control+Windows+Alt+Backspace。連按兩次會將播放裝置音量設為 50，應用程式與錄音裝置音量設為 100，並全部取消靜音。
  • 快速切換預設麥克風靜音：Shift+Control+Windows+Alt+向下鍵。
  • 快速切換預設系統聲音靜音：Shift+Control+Windows+Alt+向上鍵。
  • 切換目前視窗應用程式靜音：Shift+Control+Windows+Alt+空白鍵。

重設快速鍵按一次會清除所有應用程式保存的播放與錄音裝置設定，即使目前沒有列出音訊應用程式也會執行。快速連按兩次，還會將所有啟用中的播放裝置（包括喇叭與耳機）音量設為 50，應用程式工作階段與錄音裝置音量設為 100，並全部取消靜音。若已啟用麥克風音量鎖定，鎖定音量也會同步改為 100。麥克風增量與 Windows 預設裝置選擇維持不變。

使用快速鍵前，請先按 NVDA+1 關閉「輸入說明」。開啟輸入說明時，NVDA 只會朗讀快速鍵用途，不會執行指令。

麥克風增量

麥克風增量快速鍵在 NVDA 桌機配置使用數字鍵盤（九宮格），筆電配置使用上下方向鍵，不需先選取裝置。每次依硬體支援的級距調整預設麥克風增量一級，例如 0、10、20、30 dB，並報讀實際值。這兩個指令不更動一般音量及音量鎖定。若裝置未提供可辨識的 dB 增量控制，會報讀提示。
